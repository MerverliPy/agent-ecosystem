# shared/ — specs, schemas, datasets shared across products

- `schemas/` — JSON schemas (benchmark-result v1 draft, skill-manifest v1 draft, memory-event lands in Phase 5)
- `specs/` — markdown specs (skill-manifest-spec-v1)
- `datasets/` — seeded benchmark data (lands in Phase 2)

All files here are versioned and validated; nothing in `shared/` may be product-specific.
